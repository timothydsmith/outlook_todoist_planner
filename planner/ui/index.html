Settings

Connect Todoist and your Outlook calendar to get started. Everything stays on this computer, apart from the requests the app makes to Todoist and Outlook.

Todoist

In Todoist, open Settings › Integrations › Developer and copy the API token.

Uses Todoist's own filter syntax. Leave blank to show every task.

Outlook calendar

Anyone who has this link can see what you published, so keep it to yourself. "Can view titles and locations" is enough for this app.

Tasks in Outlook

Each task with a time gets its own event. Moving or resizing the event in Outlook moves the task in Todoist; deleting it removes the task's time. Turning this off removes the upcoming events Planner added.

Needs "Outlook on this PC" above.
